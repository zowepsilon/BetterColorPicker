# Better Color Picker

<img src="logo.png" width="150" alt="the mod's logo" />

This mod replaces the vanilla color picker with a more usable alternative (pictured above).

### Credits
This mod uses the `ShaderCache` implementation from [Fine Outline](https://github.com/Alphalaneous/FineOutline) by Alphalaneous.
